# BetterInternship Landing Sprite Style

Use this description when generating future landing-page artwork:

> Glossy 3D sticker-style web artwork for BetterInternship. Use vivid cobalt/royal blue as the primary color, white secondary surfaces, soft pale-blue shadows, smooth rounded plastic forms, subtle studio highlights, and a clean transparent background. The objects should feel like polished friendly startup UI assets: simple silhouettes, playful but professional, minimal detail, no dark backdrop, no text, no borders, and no flat cartoon line art. Match the existing assets in `public/homepage/`: `hero-briefcase.webp`, `hero-sparkle.webp`, `hero-plane.webp`, and `landing-bulb.webp`.

## 404 variant

Keep the composition to one centered sprite: a friendly confused student at a laptop, with a small glossy blue question mark or floating navigation cue. It should echo the old 404 illustration while using the glossy blue/white 3D landing-sprite treatment.
